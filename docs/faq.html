GenelGeneral

🎯 Fatrocu CLI ne işe yarar?

Fatrocu CLI, ImajeV-2B-Q8_0 modelini kullanarak faturaları otomatik olarak işleyen, OCR ve alan çıkarma yapan komut satırı aracıdır. PDF veya görsel faturaları tarar, tüm alanları çıkarır ve Excel/CSV olarak dışa aktarır.

🤖 Hangi model kullanılıyor?

Varsayılan olarak ImajeV-2B-Q8_0 kullanılır (2 milyar parametre, Q8_0 kuantize). Ayrıca Gemma-4-E4B-it ve Gemma-4-E2B-it modelleri de desteklenir. Modeli fatrocu models --download ile indirebilirsiniz.

⚙️ Hangi işletim sistemleri destekleniyor?

Windows 10/11 x64, Linux (Ubuntu, Debian, Fedora, Arch vb.), macOS. GPU desteği NVIDIA CUDA (CUDA 12+), AMD ROCm ile çalışır.

📦 Minimum sistem gereksinimleri nedir?

RAM: 8 GB (8GB+ önerilir)
GPU: 6 GB VRAM (opsiyonel, CPU ile de çalışır)
Diske yer: ~7 GB (ImajeV-2B-Q8_0 için)

Kurulum & KullanımInstallation & Usage

📥 Model nasıl indirilir?

fatrocu models --download ImajeV-2B-Q8_0 komutu ile indirilir. Model otomatik olarak %APPDATA%\Fatrocu\models\ dizinine kaydedilir. İndirme ilerleme çubuğu ile takip edilir.

🔧 llm-cli nedir ve neden gerekli?

llama-cli (llama.cpp'ın komut satırı aracı), GGUF modellerini çalıştırmak için kullanılır. Modeli indirdikten sonra, llama-cli.exe dosyasını sistem PATH'inize eklemeniz gerekir. Örnek: PATH=C:\Users\{USER}\AppData\Roaming\Fatrocu\bin;%PATH%

💻 pip bağımlılıkları nasıl kurulur?

pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu124
pip install excelize python-dateutil python-dotenv

Performans & OptimizasyonPerformance & Optimization

⚡ CPU vs GPU performans farkı nedir?

Intel i7-13700K (CPU): ~55 token/s
NVIDIA RTX 4090 (GPU): ~280 token/s
NVIDIA RTX 4060: ~160 token/s
Intel Arc A770: ~140 token/s

Not: GPU katmanlarını ayarlamak için --gpu-layers N kullanın. 24GB VRAM için önerilen: --gpu-layers 45

🔄 Thread sayısı nasıl ayarlanır?

--threads N ile ayarlanır. Çoklu çekirdekli CPU'lar için önerilen: --threads 8 (i7-13700K gibi 16 çekirdekli CPU'larda). Daha düşük çekirdekli sistemlerde (i5-1235U gibi) --threads 2 daha iyi sonuç verebilir.

🌡️ Temperature parametresi ne işe yarar?

Temperature, modelin rastgelelik seviyesini kontrol eder.
0.1 — 0.2: Yüksek doğruluk (OCR için ideal)
0.3 — 0.5: Dengeli
0.7+: Daha yaratıcı, daha az tutarlı sonuçlar
Varsayılan 0.2 fatura okuma için idealdir.

📏 Context pencresi ne kadar?

Varsayılan olarak --n-predict 2048 (2048 token). Büyük faturalar için artırılabilir: --n-predict 4096. Ancak daha yüksek değerler işlem süresini artırır.

Sorun GidermeTroubleshooting

❌ "llama-cli bulunamadı" hatası

llama-cli.exe dosyasını sistem PATH'inize ekleyin. Örnek:
mkdir -p "C:\Users\%USER%\AppData\Roaming\Fatrocu\bin"
copy "C:\Program Files\Python311\Lib\site-packages\llama_cli\llama-cli.exe" "C:\Users\%USER%\AppData\Roaming\Fatrocu\bin"
setx PATH "%PATH%;C:\Users\%USER%\AppData\Roaming\Fatrocu\bin"

❌ "Model bulunamadı" hatası

Model dosyasını indirin: fatrocu models --download ImajeV-2B-Q8_0. Veya model dosyasını manuel olarak %APPDATA%\Fatrocu\models\ dizinine kopyalayın.

❌ "Model dosyası bulunamadı" hatası

Model dosyasının yolunu kontrol edin. FATROCU_MODEL_PATH ortam değişkenini kullanarak özelleştirin: setx FATROCU_MODEL_PATH "C:\models\imajeV.gguf"

❌ "JSON parse error" hatası

ImajeV modelinin çıktısında JSON dışında metin varsa, --temp 0.1 ile temperature'ı düşürün. Ayrıca --system-prompt ile özelleştirilmiş sistem prompt kullanabilirsiniz.

❌ "GPU katmanları yüklenmedi"

CUDA kurulu olduğundan emin olun. NVIDIA sürücülerini güncelleyin. --gpu-layers 45 ile katman sayısını ayarlayın. Eğer GPU bulunamazsa, program otomatik olarak CPU'ya geçiş yapar.

❌ PDF'ler işlenmiyor

PDF'ler otomatik olarak sayfalarına ayrıştırılır. Her sayfa ayrı ayrı işlenir. Çok büyük PDF'ler (20+ sayfa) için, önce PDF'yi PDF24 Tools ile daha küçük parçalara ayırmayı deneyin.

Özellikler & SınırlamalarFeatures & Limitations

✅ Desteklenen formatlar

PDF, PNG, JPG, JPEG, TIFF, BMP. PDF'ler otomatik sayfa sayısına göre işlenir. Görsel kalitesi düşük (300 DPI'den daha düşük) faturalar için önce görüntüyü artırmayı deneyin.

✅ Çıkan alanlar

cari_unvan (şirket adı), cari_vergi_no (VKN), fatura_no, fatura_tarihi, ettn_uuid, mal_hizmet_toplam_matrah, kdv_orani, kdv_tutari, genel_toplam, kalemler (satır başına ürün adı, miktar, birim fiyat, toplam).

✅ Dışa aktarma formatları

Excel (.xlsx), CSV (.csv), JSON (.json). Excel dosyaları her sayfa için ayrı bir tablo içerir.

⚠️ Sınırlamalar

Çok karmaşık faturalar (çok sayıda sayfa, çok sayıda satır) için performansı düşebilir. Çok küçük metinler (10px'den küçük fontlar) okunmayabilir. Çok düşük kalite (600 DPI'den düşük) PDF'ler hatalı sonuçlar verebilir. Çok bulanık veya kırık faturalar okunamayabilir.

Geliştirme & KatkıDevelopment & Contributing

🔧 Kaynak kodu nerede?

[GitHub'dan klonlayın](https://github.com/Nec0ti/Fatrocu). Rust ile yazılmıştır — cargo build --release ile derleyebilirsiniz.

🐛 Hata bildirmek istersem?

GitHub Issues'dan [hata bildirimleri](https://github.com/Nec0ti/Fatrocu/issues) açabilirsiniz. Lütfen hata bildirimlerinde: Rust sürümü, model adı, işletim sistemi, Python sürümü, ve hatanın tam mesajını paylaşın.

📝 Kendi modeli kullanmak istersem?

Evet! fatrocu models --import ./model.gguf ile kendi GGUF modelinizi yükleyebilirsiniz. Veya doğrudan --model-path ile özelleştirilmiş bir model kullanabilirsiniz.
