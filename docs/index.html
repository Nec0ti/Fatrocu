Fatrocu CLI

v3.1.0

İmajeV-2B-Q8_0 ile güçlendirilmiş, tamamen yerel çalışan fatura işleme aracı. OCR + alan çıkarma tek bir model çağrısında.

Özellikler

⚡

Hızlı İşleme

~55 token/s (CPU) / ~280 token/s (GPU). İmajeV-2B-Q8_0 ile saniyeler içinde sonuç.

🔒

%100 Yerel

Veri hiç internete gitmez. Tüm işlemler bilgisayarınızda gerçekleşir.

🤖

İmajeV-2B-Q8_0

2 milyar parametreli, hafif ve güçlü bir görsel-dil modelü. OCR + çıkarma tek adımda.

📄

PDF & Görsel

PDF, PNG, JPG, TIFF, BMP formatları desteklenir. Otomatik sayfa ayrıştırma.

📊

Excel/CSV Export

İşlenen faturaları Excel veya CSV olarak dışa aktarın.

🎯

Tam Otomasyon

Sadece modeli indirin, uygulamayı çalıştırın — geri kalanını biz hallederiz.

API Referansı

process

fatrocu process \
    --model <model-adi> \
    --model-path <model.gguf> \
    --image <gorsel|pdf> \
    --output <sonuc.json> \
    --temp 0.2 \
    --n-predict 2048 \
    --threads 4 \
    --gpu-layers 0

Bir fatura görseli veya PDF'yi işler. İmajeV-2B-Q8_0 modeli kullanılarak OCR ve alan çıkarma yapılır. Sonuç JSON olarak kaydedilir.

models --download

fatrocu models --download "ImajeV-2B-Q8_0" \
    --url https://huggingface.co/Qwen/Qwen2.5-VL-7B-Instruct/resolve/main/Qwen2.5-VL-7B-Instruct-Q4_K_M.gguf \
    --output models/Qwen2.5-VL-7B-Instruct-Q4_K_M.gguf

Bir modeli HuggingFace'den indirir ve yerel dizine kaydeder. İndirme ilerleme çubuğu ile gösterilir.

export --format xlsx

fatrocu export \
    --format xlsx \
    --output "Fatrocu_Raporu.xlsx" \
    --status reviewed

İşlenen faturaları Excel dosyası olarak dışa aktarır. Her sayfa bir faturanın detaylarını içerir.

Ortam Değişkenleri

PATH

llama-cli.exe'nin bulunacağı dizin PATH'e eklenmelidir.

FATROCU_MODEL_PATH

Model dosyasının tam yolu. Varsayılan: %APPDATA%\Fatrocu\models\

FATROCU_THREADS

İşlem sayısı. Varsayılan: 4

FATROCU_TEMP

Örneklemleme sıcaklığı. Varsayılan: 0.2

Sık Sorulan Sorular

Hangi modelleri destekliyorsunuz?

İmajeV-2B-Q8_0 (varsayılan), Gemma 4 E4B, Gemma 4 E2B. Ayrıca kendi GGUF modellerinizi de yükleyebilirsiniz.

Hangi işletim sistemlerini destekliyorsunuz?

Windows 10/11 x64, Linux, macOS. GPU desteği NVIDIA CUDA, AMD ROCm ile çalışır.

Ne kadar disk alanı gerekir?

İmajeV-2B-Q8_0 için ~7 GB. Gemma 4 E4B için ~4.8 GB, E2B için ~2.8 GB.

Hangi dosya formatlarını kabul ediyorsunuz?

PDF, PNG, JPG, JPEG, TIFF, BMP. PDF'ler otomatik olarak sayfa sayısına göre işlenir.

GPU kullanımı nasıl ayarlanır?

--gpu-layers N ile GPU katmanlarını ayarlayabilirsiniz. 24 GB VRAM için önerilen: --gpu-layers 45

Hangi GPU'lar destekleniyor?

NVIDIA CUDA (CUDA 12+), AMD ROCm, Intel Arc. M.2 NVMe SSD önerilir.

Bağımlılıkları nasıl kuruyorum?

pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu124
pip install excelize python-dateutil python-dotenv
