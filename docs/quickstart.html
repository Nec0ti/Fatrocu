Fatrocu CLI

v3.1.0 — Hızlı Başlangıç

İlk Adımlar

1

Adım 1 — Kurulum

  • git clone https://github.com/Nec0ti/Fatrocu.git
  • cd Fatrocu/fatrocu-cli
  • cargo build --release

Not: İlk çalıştırmada llama-cli.exe otomatik olarak indirilir. Model sayfasına bakın.

2

Adım 2 — Model İndirme

  • cargo run --release -- models --download "ImajeV-2B-Q8_0"

Beklenen çıktı:

✅ Model indirildi: İmajeV-2B-Q8_0.gguf (6.98 GB)

✅ Model hazır!

3

Adım 3 — İlk İşlem

  • cargo run --release -- process --model "İmajeV-2B-Q8_0" --image "fatura.pdf" --output "sonuc.json"

Beklenen çıktı:

✅ Fatura işlendi. Sonuç: sonuc.json

İşlem süresi: ~3-5 saniye (CPU) / ~1-2 saniye (GPU)

4

Adım 4 — Sonuçları İnceleme

  • cargo run --release -- list
  • cargo run --release -- status

fatrocu status komutu ile motorun hazır olduğunu doğrulayın.

5

Adım 5 — Excel İhracat

  • cargo run --release -- export --format xlsx --output "Fatrocu_Raporu.xlsx"

Excel dosyası, her fatura için ayrı bir tablo içerir. Sayfa başlıkları fatura numaralarıdır.

6

Adım 6 — İleri Kullanım

  • cargo run --release -- process --model "ImajeV-2B-Q8_0" --image "fatura.pdf" --temp 0.3 --threads 8 --gpu-layers 32

Advanced parametreler: --temp (temperature), --threads (işlem sayısı), --gpu-layers (GPU katmanları).
